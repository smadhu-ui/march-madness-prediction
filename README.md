# 🏀 March Madness Prediction | Machine Learning Datathon

## 📌 Project Overview

This project was developed as part of a March Madness Datathon to predict NCAA basketball tournament outcomes using machine learning.

The goal was to analyze historical team performance data, identify the factors associated with tournament success, and build a predictive model for tournament matchups.

## 🎯 Objective

Build a machine learning model capable of predicting March Madness tournament outcomes and use the model to generate predictions for the tournament bracket.

## 🤖 Machine Learning Approach

- Data cleaning and preprocessing
- Exploratory data analysis
- Feature selection
- Random Forest classification
- Model evaluation
- Tournament outcome prediction

## 📊 Results

- Achieved approximately **76% prediction accuracy**
- Predicted the **Final Four teams**
- Generated a tournament bracket using model predictions
- Predicted **Tennessee** as the tournament champion
